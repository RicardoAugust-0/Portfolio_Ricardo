💻 Portfólio Pessoal - Ricardo Augusto

Este repositório contém o código-fonte do meu portfólio pessoal, uma aplicação web de página única projetada para apresentar minha trajetória, projetos e habilidades técnicas como Desenvolvedor Front-End Júnior.

O objetivo deste projeto é oferecer uma interface limpa, rápida e responsiva que sirva como um hub central para minhas informações profissionais, integrando experiências reais e projetos acadêmicos.
🚀 Tecnologias Utilizadas

A aplicação foi construída utilizando ferramentas modernas do ecossistema JavaScript para garantir performance e manutenibilidade:

    Vite + React: Para uma estrutura de desenvolvimento rápida e componentização eficiente.

    TailwindCSS: Para uma estilização utilitária, garantindo um design responsivo e consistente.

    Shadcn/UI: Componentes de interface minimalistas e acessíveis.

    Framer Motion: Implementação de animações fluidas de scroll (fade-in, slide-up) e interações dinâmicas.

    Lucide React: Conjunto de ícones vetoriais para uma interface intuitiva.

✨ Funcionalidades

    Design Clean Tech: Interface focada na legibilidade e experiência do usuário.

    Modo Escuro/Claro: Suporte nativo para alternância de temas.

    Animações de Scroll: Elementos que surgem suavemente conforme a navegação.

    Timeline de Experiência: Exibição estruturada da trajetória profissional, incluindo passagens pela MedNet Paulínia e CRZ Instalações.

    Grid de Habilidades: Categorização clara de competências em Frontend, Backend, Infra e Ferramentas.

📂 Projetos em Destaque no Portfólio

O portfólio apresenta detalhadamente projetos como:

    Moovox (TCC): Plataforma de telemetria e geolocalização animal de baixo custo utilizando React e Node.js.

    Projeto Nexus: Um CRM/Plataforma completo construído com React, Supabase e TailwindCSS.

    API REST (Gestão): Sistema de gerenciamento de pedidos e produtos desenvolvido em Node.js e Express.
