## 📦 Como Rodar Localmente

### Com Docker 🐳

```bash
# Build a imagem
docker build -t portfolio-ricardo .

# Rode o container
docker run -p 5173:5173 portfolio-ricardo
```

### Sem Docker

```bash
# Clone o repositório
git clone https://github.com/ricardo-augusto/portfolio.git

# Entre na pasta
cd portfolio

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev

# Build para produção
npm run build
```

A aplicação estará disponível em `http://localhost:5173`
