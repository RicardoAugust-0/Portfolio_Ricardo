💻 Portfólio Pessoal - Ricardo Augusto

Este repositório contém o código-fonte do meu portfólio pessoal, uma aplicação web projetada para apresentar minha trajetória, projetos e habilidades como Desenvolvedor Front-End Júnior.

O objetivo deste projeto é oferecer uma interface limpa e responsiva que sirva como um hub central para minhas informações profissionais.
🚀 Tecnologias Utilizadas

A aplicação foi construída utilizando ferramentas modernas para garantir performance e manutenibilidade:

    Vite + React: Estrutura de desenvolvimento rápida e componentização.

    TailwindCSS: Estilização utilitária e design responsivo.

    Shadcn/UI: Componentes de interface minimalistas e acessíveis.

    Framer Motion: Implementação de animações fluidas de scroll.

    Lucide React: Conjunto de ícones vetoriais.

✨ Funcionalidades

    Design Clean Tech: Interface focada na legibilidade.

    Modo Escuro/Claro: Suporte nativo para alternância de temas.

    Animações de Scroll: Elementos que surgem suavemente conforme a navegação.

    Timeline de Experiência: Exibição estruturada da trajetória profissional.

    Grid de Habilidades: Categorização de competências em Frontend, Backend, Infra e Ferramentas.

📂 Projetos em Destaque

    Moovox (TCC): Plataforma de telemetria e geolocalização animal de baixo custo utilizando React e Node.js.

    Projeto Nexus: CRM/Plataforma completo construído com Vite, React, Supabase e TailwindCSS.

    API REST (Gestão): Sistema de gerenciamento de pedidos e produtos desenvolvido em Node.js, Express e Axios.

🎓 Formação e Experiência

    Educação: Atualmente cursando Análise e Desenvolvimento de Sistemas na Fatec Paulínia.

    Trabalho Atual: Auxiliar Administrativo na MedNet Paulínia, atuando no Programa Fadiga Zero com sistemas de telemetria e gestão de dados críticos.

🛠️ Como Executar o Projeto
Bash

# Clone o repositório
git clone https://github.com/RicardoAugust-0/portfolio.git

# Entre na pasta
cd portfolio

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
